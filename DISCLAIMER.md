# Disclaimer

`transaction_intent_signer` is an open-source **developer infrastructure**
package. It is provided under the MIT License, as-is, without warranty.

## What this package is not

This package is **not**:

- a regulated financial product
- a KYC system
- an AML system
- an identity verification solution
- a biometric authentication product
- a fraud prevention or fraud scoring engine
- a credit decisioning system
- a loan origination system
- a payment processor
- legal advice
- a compliance certification
- a production WebAuthn / passkey server
- a substitute for institution-specific risk, legal, or compliance controls

## Correct positioning

The package creates **audit-friendly technical artifacts** that can support
transaction intent verification workflows. It does **not** make identity,
fraud, credit, legal, or compliance decisions.

Do not claim that this package:

- prevents fraud
- proves user identity
- guarantees user consent
- is “court-proof” evidence
- fully complies with E-SIGN, TILA, or other legal regimes by itself
- replaces banking compliance systems

Institutions remain responsible for their own regulatory interpretation,
vendor due diligence, key management, authenticator integration, and audit
retention policies.
